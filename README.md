# FoodGo — Delivery Web

Aplicativo web de delivery feito com React + JSX + Vite.

## Executar

```bash
npm install
npm run dev
```

Depois acesse o endereço mostrado pelo Vite, normalmente `http://localhost:5173`.

## Recursos

- Pesquisa de pratos e restaurantes
- Filtro por categorias
- Banner promocional
- Produtos com imagem, avaliação e tempo
- Adição ao carrinho
- Carrinho fixo com total
- Layout responsivo para PC e celular
